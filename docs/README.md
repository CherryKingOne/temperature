# Temperature 平台接口文档

本目录存放 Temperature 平台全部接口文档，按调用方与业务域分目录组织。

## 目录结构

```
docs/
├── api/
│   └── admin/            # 平台管理端（admin）接口
│       ├── auth/         # 登录认证相关
│       └── ...
└── ...
```

## 约定

### 基础信息

| 项 | 值 |
| --- | --- |
| 服务名 | temperature-backend |
| API 前缀 | `/api/admin` |
| 管理端接口文档目录 | `docs/api/admin/` |
| 认证方式 | `Authorization: Bearer <access_token>` |

### 统一响应结构

所有接口均返回统一 JSON 信封：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "request_id": "0f0d9a6e1b2c4d8e"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 业务状态码，`0` 表示成功，非 `0` 表示失败 |
| `message` | string | 提示信息，失败时为可直接展示给用户的中文文案 |
| `data` | object \| null | 业务数据，失败时为 `null` |
| `request_id` | string | 请求追踪 ID，排查问题时提供 |

### 业务状态码

| code | HTTP | 含义 |
| --- | --- | --- |
| `0` | 200 | 成功 |
| `40001` | 422 | 请求参数校验失败 |
| `40100` | 401 | 未登录或访问令牌无效/过期 |
| `40101` | 401 | 刷新令牌无效或已失效 |
| `40102` | 401 | 账号或密码错误 |
| `40103` | 401 | 账号已被禁用 |
| `40300` | 403 | 无权限访问该资源 |
| `40400` | 404 | 资源不存在 |
| `40900` | 409 | 资源冲突（如邮箱已被注册） |
| `42200` | 422 | 业务规则不满足（如验证码错误/已过期） |
| `42900` | 429 | 请求过于频繁，请稍后再试 |
| `50000` | 500 | 服务器内部错误 |
| `50300` | 503 | 依赖服务不可用（邮件服务、缓存服务） |

### 时间与字段格式

- 时间统一使用 ISO 8601（UTC），例：`2026-10-20T08:33:25Z`
- 日期统一使用 `YYYY-MM-DD`
- 邮箱统一转小写后存储与比对
- 布尔值使用 JSON 原生 `true` / `false`
